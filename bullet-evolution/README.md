# 彈幕進化

單檔 HTML 彈幕射擊遊戲。基因演化驅動的敵人生態 + 抽卡式武器收集。

## 版本

檔名帶版號：`彈幕進化-v0.5.html`。每次改版同步更新檔名與遊戲內的版本標示。

## 玩

直接用瀏覽器開 `彈幕進化-v0.5.html` 就行。沒有伺服器、沒有依賴、沒有網路請求。

手機上建議用瀏覽器的「加入主畫面」當 App 用。

## 怎麼玩

- 在畫面**下半部按住拖曳**，出現虛擬搖桿移動機體，武器自動開火
- **躲開**彩色子彈。5 顆愛心，被打中扣 1 顆，每過一波回 1 顆
- 你變強，敵人也跟著變強
- **擊落敵人**會讓新武器加入卡池，選到就跟現有武器一起開火
- 每 5 波選一張技能卡，每 10 波進化一次基因
- 右上 **❚❚** 暫停、**☰** 設定與圖鑑

## 難度

開始畫面可調整**雙方子彈速度**（×0.30 ～ ×1.60）。

注意這個滑桿同時影響敵人和你自己的子彈速度。往「慢」拉是整個遊戲變慢，
不是單純變簡單。覺得太慢打不贏的話，敵血成長係數需要另外調整。

## 開發

```
彈幕進化-v0.5.html      遊戲本體（單檔，229 行）
dist/index.html      部署用副本
docs/技術文件.md      技術文件：基因系統、平衡數據、已知問題
```

語法檢查：

```bash
node -e "const fs=require('fs');fs.writeFileSync('/tmp/c.js',fs.readFileSync('彈幕進化-v0.5.html','utf8').match(/<script>([\s\S]*)<\/script>/)[1])"
node --check /tmp/c.js
```

部署前 `cp 彈幕進化-v0.5.html dist/index.html`。

改版的詳細流程與所有平衡數值見 [docs/技術文件.md](docs/技術文件.md)。
